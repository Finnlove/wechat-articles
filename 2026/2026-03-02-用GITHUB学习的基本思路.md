### 1. NCE-Flow（最推荐，点读 + 交互）

* 项目名：**NCE-Flow**（也叫 NCE Flow）
* 地址：https://github.com/luzhenhua/NCE-Flow （原作者）
* 功能：**全四册在线点读、单句播放、倍速、中英对照、循环、进度记录**
* 特点：纯静态、可本地部署、界面现代、零依赖
* 在线体验：https://nce.daimazhan.com

### 2. iChochy/NCE（经典全四册点读）

* 项目名：**NCE**（iChochy/NCE）
* 地址：https://github.com/iChochy/NCE
* 功能：**全四册课文朗读、单句点读、中英对照、网页直接用**
* 特点：轻量、Stars 900+，适合直接在线 / 本地部署

### 3. NewConceptEnglish（学习笔记 + 资料）

* 项目名：**NewConceptEnglish**
* 地址：https://github.com/andylee1890/NewConceptEnglish
* 内容：NCE2/3/4 学习笔记、解析、辅助资料

### 4. wish1776/NCE（语法 + 译文）

* 项目名：**NCE**（wish1776/NCE）
* 地址：https://github.com/wish1776/NCE
* 内容：NCE2/3/4 原文 + 译文 + 详细语法分析

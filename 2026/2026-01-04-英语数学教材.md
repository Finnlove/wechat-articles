看这里，多么地道的表述：a handful of cubes,我们很多大学生都写不出这样地道又简单的表述，一捧什么什么。其实这个handful是非常象形的一个单词，hand是✋️手，对吧，那么ful是一个常见的形容词的后缀，又和full很相近，那么手里满了，是不是就是一捧啊？因此我们可以扩展：

1. **形容词**：描述一种“充满…特质”的状态

* `beautiful` = beauty (美) + -ful = 充满美的 → **美丽的**
* `careful` = care (小心) + -ful = 充满小心的 → **仔细的**
* `powerful` = power (力量) + -ful = 充满力量的 → **强大的**

2. **名词（量词）**：表示“能装满一个…的量”

* `handful` = hand (手) + -ful = 装满一只手的量 → **一把**
* `mouthful` = mouth (嘴) + -ful = 装满一张嘴的量 → **一口**
* `spoonful` = spoon (勺子) + -ful = 装满一勺子的量 → **一勺**

是不是压根不用一个一个背单词了？因此，这个不仅仅是一本数学书，反而是一本非常好的高质量的语言学习书。

这里有个有趣的词叫做Ladybird，可以让孩子猜猜这个是什么东西啊？我们学过Ladybug,是瓢虫的意思🐞，那么这里的Ladybird还是昆虫的意思，是一种对昆虫的戏称，那么为什么会把Lady这个词联想到虫子呢？

在中世纪欧洲，农作物常受蚜虫侵害。农民向圣母玛利亚祈祷后，这种甲虫大量出现，吃光了害虫，拯救了庄稼。人们认为这是圣母的恩赐，于是称它为 **“Our Lady's beetle”**（圣母的甲虫）

这个Lady指的是女神，这些虫子因为会飞，被称为小鸟或者长翅膀的小生灵。所以发展到Ladybug\ladybird。甲虫我们在年级阅读中学过，七星的是益虫，因为它吃别的小虫子，那么14星瓢虫是害虫，因为它吃素。所以这个LadyBug其实是指的那些有益的昆虫。

这种昆虫有戏称名字的现象在中文中也出现过：比如我们北方一些地方管一些瓢虫叫做花大姐，那些会散发臭味的则叫做臭大姐。

像这样我们有导入，有场景，有文化背景的介绍，有中英文渊源的对比，还会有人记不住这些单词么？

那接下来孩子听了有趣的背景故事以后就完全明白这个题目要求他来做什么了，大部分孩子都会愉快的把这个画个数当成一种游戏来做。这就是快乐教育的真相：以一种超高维度的思维和互动模式来推动知识和心智的自然融合。

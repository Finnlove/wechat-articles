有一些人可能喜欢学习python，以下是deepseek整理的清单：

### **1. Blockly（Python 代码生成）**

* **网址**：https://blockly.games/python
* **特点**：

+ 谷歌开发的图形化编程工具，通过拖拽积木生成 **Python 代码**。
+ 适合初学者理解 Python 基础语法和逻辑。这个说实话，实在有点简陋啊，过于工业码农风
+ ![](https://mmbiz.qpic.cn/mmbiz_png/TZaiaIvaGzrejyxL1ibHaFfnQ2vOMJyZoibESibIBROVeYmlRD1NzJJic6pVU7qgcVancekjR5DrdCOKQzzokhdUFsw/640?wx_fmt=png&from=appmsg)

---

### **2. MakeCode Python（硬件/游戏开发）**

* **网址**：

+ Microbit 版：https://makecode.microbit.org/#python
+ Arcade 版：https://arcade.makecode.com/#python

* **特点**：

+ 微软开发，支持在图形化界面和 **Python 代码** 之间切换。
+ 可编程 Micro:bit 硬件或开发 2D 小游戏。还是微软有钱一些，整的好看多了，关于micro bit的硬件可以在拼多多直接买到。

  ![](https://mmbiz.qpic.cn/mmbiz_png/TZaiaIvaGzrejyxL1ibHaFfnQ2vOMJyZoibcujDJicIcnWmHX3fIzJxQGYh2JyVS0XCJEdGTe2k1QQek6UTukssZ0g/640?wx_fmt=png&from=appmsg)

### **3. Trinket（在线 Python 图形化学习）**

* **网址**：https://trinket.io/python
* **特点**：

+ 直接在浏览器中编写/运行 Python 代码，支持 **Turtle 绘图** 和 **Pygame**。
+ 免费版有基础功能，适合教学和简单项目。

---

### **4. CodeCombat（游戏化学 Python）**

* **网址**：https://codecombat.com
* **特点**：

+ 通过游戏关卡学习 Python（需输入代码，但有可视化反馈）。
+ 部分免费，适合青少年或趣味学习。这个据我所知是和清华大学合作商业化了，后面的课程会收费。

---

### **5. PythonTurtle（交互式绘图）工业风**

* **网址**：https://pythonturtle.org
* **特点**：

+ 基于 Python 的 Turtle 绘图库，直接在网页中编写代码控制小海龟绘图。
+ 极简界面，适合练习基础 Python 语法。这个太工业废墟风了。
+ 然后教程油管太多太多太多了，多到无力介绍。为什么说英语环境是学习的天堂，因为太多免费的了，中文的一比一汉化一下都收你个几千块，就大无语。

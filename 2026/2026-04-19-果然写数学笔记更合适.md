### 哥尼斯堡七桥问题

欧拉的经典数学题来啦：  
镇中心有一条河，河上有**两个小岛**，岛和两岸之间由**七座桥**连接（如图![👇](https://mmbiz.qpic.cn/sz_mmbiz_png/Fr4ehPkklcibnzme9AvNu4Y2GFWbViaJ8rtxO0wZ4pdZkRdaibwoYQfp3l3aVj4fQQIgV90xzkhcTf2v4x3ibLOUML3WAbJXqkgaoreXDHy3X1M/640?wx_fmt=png&from=appmsg)）。

```
     北岸  
  /   |   \  
桥1  桥2   桥3  
/     |     \  
岛A---桥4---岛B  
|      |      |  
桥5   桥6   桥7  
  \   |   /  
    南岸
```

有一个显得蛋疼的人提了一个问题：**能不能从某个地方出发，一次走遍这七座桥，但每座桥只走一次，最后回到起点？**  
很多人为了证明这个问题，反复的桥上来回的走啊跑啊，结果自己跑晕了都没搞清楚到底可不可以。欧拉是个宅男，他才不会去现场跑来跑去，他用点和线把这个问题整理成一笔画问题，就是说一笔连上所有的点。  
那么整理有：

* **岛A**

  ：连接了 **5座** 桥（1,2,4,5,6） → **5是奇数** → **奇点** ![💥](https://mmbiz.qpic.cn/mmbiz_png/Fr4ehPkklc9hd7Z4HtwxicTic2GiaIHiam6JQK4vgPbYumWy1iae4USlcRLNTqZ8LzxSUibJps3qBPYYsHR08SIdBTEomSibCmjzmo4f9eib8lqWgbM/640?wx_fmt=png&from=appmsg)
* **岛B**

  ：连接了 **3座** 桥（3,4,7） → **3是奇数** → **奇点** ![💥](https://mmbiz.qpic.cn/sz_mmbiz_png/Fr4ehPkklc9lIFy224Wd0FibLknECt9y3wmLTtLlh9SMSOpfbBuTibPLprHcm3oVreK9EANZ0YFfnBucHsGYKI1PNwgzWIDtHibZlEwbZfic8Ow/640?wx_fmt=png&from=appmsg)
* **南岸**

  ：连接了 **3座** 桥（5,6,7） → **3是奇数** → **奇点** ![💥](https://mmbiz.qpic.cn/sz_mmbiz_png/Fr4ehPkklc9ia0FOH8xufPC5YuXYxCqjsNX2vUfrcpJWfaqoDicIfKdxTDfaibmHxjnyVd9ickOT0sXGj5xicQEKTSgHyicIzmq5fF2eNnX2LkhcE/640?wx_fmt=png&from=appmsg)
* **北岸**

  ：连接了 **3座** 桥（1,2,3） → **3是奇数** → **奇点** ![💥](https://mmbiz.qpic.cn/mmbiz_png/Fr4ehPkklc90xYCZPr5cChCwAh6OCxZZhC6AjxjGtIG1vnGt4LsEBmVtr1L4LebiatyF0fdrclia6YxPxkGcFZ6WXCutnlEP0ZicJbSoybiakpY/640?wx_fmt=png&from=appmsg)
* 这都四个奇点了

显然都不行，所以欧拉就宣布，你们别吵了，看图，就是不行。  
这还没完，他还顺手发表几篇著作开创了数学里的 《图论》 和 《拓扑学》。这人一辈子写了800多篇著作，什么题材只要他发现了都能整成数学论文。

有人说这类问题完全就是弄出来整人的，有什么实际用处啊？当然有了，送外卖就首先用的上啊。比如你现在是外卖小哥，精通图论，每次送餐你都规划一条不走回头路，送完所有点的最优路径，年年都是单王。![🤣](https://mmbiz.qpic.cn/sz_mmbiz_png/Fr4ehPkklc88F1ygXk6m08CLZynf2tOicziaTqcnJPEoeqMJf5TTUrW3VPDhzKjQWqBjPyZsKwwJCxw7grfFPEOOdicJlCskibLdNVUH2hTsRho/640?wx_fmt=png&from=appmsg)  
再比如手势密码，你总得设置成一笔能画出来的吧，不然一只手怎么解锁。

------------八卦分界线--------------

为什么这么多同龄人离婚，咱也不敢问，只知道有个男同学离婚以后再婚，又找了一个抽烟喝酒的，和他以前的那位实在是风格相差巨大。还有两个我知道已经离很久了，然后一直不结婚，咱也不敢问为什么。还有，高中的班花也离婚了，我曾经以为那种学习好又是班花的女孩子不会有感情上的烦恼，事实证明婚姻和长相、财富、性格关系都不大，基本就是玄学。如此看来，还是小学数学简单多了，一就是一，二就是二。

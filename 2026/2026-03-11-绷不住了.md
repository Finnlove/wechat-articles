就发广这天吧，老想吐槽了，雷是一波接一波。首先是英语老师暴击，娃说老师把let's dance along翻译成一起向前跳舞。我说那不是上一句let's  move  on么？娃说就是这个dance这一句这样翻译的。我了个天，什么情况，这是哪里来的体育老师冒充的英语老师吧。有一首歌yesterday once more，里面有句歌词：When they played I'd sing along，会唱吧，哪个会翻译成我一起向前唱的？这明显就是我跟着一起唱啊。

然后我再问老师讲了特殊疑问代词没？复合名词讲了没，可数名词不裸奔讲了没？答，一个都没讲。没办法了，我只能good nice brilliant三连，这是遇到了仙人老师，会一点的随便讲讲，不会的直接乱讲啊。

语文老师也好不到哪里去，本来想放图的，怕被认出来。

反正他们这个板书，这个导图画的，这个排版，我只能说，娃能对着这个板书把字写好看，简直就是天才中的天才，全靠自学。😅这么密密麻麻的思维导图，我实在是看得心累。问，你们老师怎么教思维导图的啊，答，就是画一个东西在中间，然后连出来这些，斜着写就行了。只有“堆内容”，没有“理结构”，模块边界模糊、文字拥挤、重点全靠颜色乱标，娃能看懂全靠自己悟。

好好好，一个要点都没点明，思维导图的框架，中心点是什么，什么是主体，什么是框架层次都没说呗。重新返工自己教了一遍，终于扯明白了。还有之前贴的那个课课贴，娃说太有用了，很有帮助，听不懂的地方看看课课贴就明白了。

数学老师目前还好，终于有一门暂时没有暴击我的。娃总结了一下，太难了，不仅要学会，还要防着老师乱教啊。😅反过来想，批判思维这不就从小就有了，只能这样安慰自己了。

讲道理啊，前几天听到ai培训进学校，终于有一个砖家提到了多维表啊、数据库这些词了，不是之前那个吊北京来的鸟玩意专家，什么ai生图，ai数字人这类狗屁不通的花架子了，可惜他也是知道一点，但懂的不多，再往后他就不会了。我说能不能正经派个it人士来讲啊，这些骗吃骗喝混津补贴的中小学砖家懂个锤子的ai。

还有说龙虾的，听的我想笑，知道什么是龙虾么。OpenClaw 基于开源的 MCP 协议（Model Context Protocol），通过标准化 API 连接各类数据与工具。我们和龙虾对话，本质是：发文本指令 → 模型拆解任务（经 MCP 解析） → 通过 API 获取数据 → 整理成标准格式 → 调用工具执行 → 输出结果。像息流目前自己搞了一个新的基于mcp的工具，但是这类路线对token的消耗是巨量的，我个人不看好。我觉得对于龙虾的热潮可以让子弹飞一会。

## 🧩 四、重点句式&语法表

> 打印建议：A4纸横向，彩色打印，贴在课本对应单元页，方便随时复习

|  |  |  |  |
| --- | --- | --- | --- |
| 句式/语法 | 结构 | 课文例句 | 考点&易错点 |
| 🟥 一般过去时 | 主语 + 动词过去式 （规则加-ed，不规则特殊变形） | He jumped out of bed. hated loved thought fell ate | 描述过去动作📕 必背不规则变形：go-went eat-ate fall-fell think-thought |
| 🟧 过去进行时 | was/were + 现在分词(doing) | He was lying in bed. | 过去某一时刻正在做的动作🛌 |
| 🟨 be late for 固定搭配 | be late for + 地点/活动 | He was late for school. | 固定搭配，绝对不能加to⏰ |
| 🟩 because 原因状语从句 | …because + 完整句子 | I'm late because our dog ate my maths homework | 回答why的问题； because和so不能同句连用❌（二选一） |
| 🟦 so/so that 状语从句 | …so + 结果句 / …so that + 目的句 | so I had to do that again so he had to run really fast | so表结果，so that表目的，注意区分⚠️ |
| 🟪 have to 情态动词 | have to / had to + 动词原形 | I had to do that again he had to run really fast | 表示“不得不”，had to是过去式； have to强调客观，must强调主观🏃 |
| 🟫 might 情态动词 | might + 动词原形 | it might take much more time to get to school | 表示“可能”，过去式形式不变； might后必须接动词原形🔮 |
| 🟪 when 时间状语从句 | When + 从句(一般过去时), 主句 | When he opened his eyes… | 故事写作“连接神器”🔗，串联时间线 |
| 🟥 宾语从句 | 动词 + (that) + 完整句子（陈述语序） | He thought (that) I'm going to be late again! | 从句必须用陈述语序； 主句过去时，从句用过去相关时态📌 |

## ✅ 超精简记忆口诀（好背版）

1. 过去时：过去动作用过去式，不规则变形要牢记

2. because/so：because和so不同句，一个句子只留一

3. be late for：迟到就用be late for，to千万别乱加

4. have to/must：have to是客观，must是主观，分清才不丢分

5. when时间句：when开头连故事，动作先后全靠它

## ✍️ 六、KET故事写作要点（满分模板📌）

| 步骤 | 写法 | 万能句型 |
| --- | --- | --- |
| 开头 | 人物+习惯+问题 | I was late for school today.⏰ |
| 发展 | 时间线+动作 | One day, I… Then… Suddenly…💥 |
| 高潮 | 意外+转折 | I saw an alien. It…👽 |
| 结尾 | 感受+总结 | It was a strange but fun day.😆 |

### 对话 / 口语常用句式

*What do you use these for? 'What do you use these for?' it asked.* 询问物品用途，口语高频

*I'm sorry I'm late. 'I'm sorry I'm late.' he said.* 道歉常用语，迟到场景万能句

*That's OK. Never mind. 'Oh, OK ... Never mind,' William said.* 安慰 / 回应道歉，口语高频

My strange morning

四年级有一个很重要的学习能力就是记笔记，当然记笔记并不是说要记得整本书密密麻麻。很多家长让孩子认真学习，认真听讲说来说去都只有那几句正确的废话，譬如你上课要认真听讲啊，你学习要专心啊。看起来很谆谆教导，实则和屁话没有区别。刚刚升入高年级的学生最大的障碍不是不知道如何做题，而是缺乏学习的具体方法和工具。家长说再多的你要认真学啊。他还是茫然的，不知道什么叫认真，不知道家长说的学好到底怎么才叫好，很多容易走偏成只要成绩好，别的就不管了，从一个极端进入到另外一个极端。

![](https://mmbiz.qpic.cn/mmbiz_png/Fr4ehPkklcicuHts0LbEic1bU9ENzqOqF34fSuvxoBibq6ib03pOEgLHXNg1ur8vgutD4k8XuI7wjiaaYHGdOo8K7vFFddw7YEDjNTwpGe5yGSqs/640?wx_fmt=png&from=appmsg)

所谓认真学习，是要建立从书本--学生--教师讲授--练习巩固--学习查漏补缺--考试验证学习效果的完整链条，不能有任何一环的缺失或者断裂。独角戏是不可能完成学习这件事的，他一定是一个系统性的整体。并且学习对于学生的方法主要有三：

自学、复盘和笔记

自学是指能在旧知识的基础上自行看懂教材，建立和新知识的联系，这是一切学习的根本路径和绝对基础。

复盘是指查漏补缺，会做的题要想出来第二种、第三种解法，并能迅速判断题型。比如这是归一还是归总，用什么算法。不会做的题要查找断裂的点在哪里，如何补上，如何融会贯通。

笔记是指把自己所学所想体系化的复述整理出来，光是对着黑板狂抄是没有用的，一定要是自己理解了，能顺利吃进去，经过大脑加工再吐出来的过程才叫笔记。为什么这个环节如此重要，是因为能吸收的营养才叫有用的营养，否则那和水浇鸭背有什么区别。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Fr4ehPkklc8wK2Wicg52u5HzPE7GJW1lj2SxGViaicTEBg2NU23c85BbqOVjbvRvhqPQ1tVQFn8SHzAyGUFbIKCmAsITicvqEpdwGvVcC4lBp48/640?wx_fmt=png&from=appmsg)

记笔记有很多方法，比如记号法、信息整理法、感悟总结法等。一般来说小学生至少要掌握记号法和信息整理法。其中记号法是最最容易掌握的，譬如画横线波浪线标记辅助阅读、标记易错和不会的难点难题、用荧光笔标记好词好句等，优点是容易上手，方便实操。

这一步看起来简单，但它实际上是在训练孩子：

> **“我知道什么值得注意。”我知道自己寻找有价值的信息和问题，这是学术研究的真理级别的起点**

信息整理法有：思维导图、表格整理、大括号排列、文氏图整理、列表整理等 是属于比较高阶的笔记用法。可以花一两年的时间慢慢培训。

感悟总结是得思维逻辑发展到一定高度，小有所成才能做到的，不急于马上掌握，一般由老师或者家长来总结，然后示范教授给学生为主。

> **AI让“整理信息”越来越容易，但真正稀缺的能力是自己“发现自己的问题、判断问题在哪里、组织自己现有的资料，选择下一步怎么学”。因为人往往能出其不意的发现机器发现不了的人性上的问题。**

英语的学习和语文的学习是可以互相迁移甚至迁跃的。例如在OD教材中教了非常多的阅读和信息整理工具，有order,sequence,list,now and then ,mian idean,details等，都可以直接挪到我们对中文的学习中来，我还发现娃的语文老师也意识到了这一点，她正在用这个方法教观潮这一课。这进一步证实了我的判断，他们的语文老师非常擅长带高年级。因此我们整理成表格：

|  |  |
| --- | --- |
| OD里的工具 | 《观潮》中的应用 |
| **Order** | 梳理文章内容的组织顺序 |
| **Sequence** | 潮来前→潮来时→潮去后 |
| **List** | 提取各部分的重要信息 |
| **Main idea** | 概括段落/部分主要内容 |
| **Details** | 找到描写声音、样子、变化的细节 |
| **key word** | 圈出能够推动理解的词语 |
| **Information organization** | 用表格、结构图重新整理课文 |

所以OD学习，实际上已经产生了一个非常好的**隐性收益**：

> **英语课本在训练阅读方法，语文课本在提供迁移场景。**

就是语文和英语的学习可以不分家，语文和信息处理的能力不分家，阅读和写作不分家，这才是真正的大语文。

数学也是一样，数学的笔记一定要有逻辑，甚至可以干干净净笔墨甚少，因为数学的笔记可以高度抽象。再就是一定要重视打草稿，因为草稿是思维的具象化过程，我们的书上字很少，但是草稿可不少。并且昨天晚上的作业也验证了我的猜想，这个数学老师是个高手。她命中的题目和我想的以及娃的堵点一模一样，丝毫不差。她命中的不是某一道题，而是孩子真正的**认知堵点**。这就已经不是简单的“押题”了。而是老师在判断：**孩子到底在哪里卡住。**然后教学直接打到这个节点，这就是牛逼老师的特征。以我自己当老师的经验来说，我甚至可以不需要考试，我就看看学生平时的作业和笔记状态我就能基本判断这孩子成绩如何，因为真正的成绩从来都不是分数，而在平时的学习痕迹中。

### 为什么“痕迹”比“分数”更真实？

| 维度 | 考试分数 | 作业与笔记痕迹 |
| --- | --- | --- |
| 时效性 | 滞后指标（反映过去） | 领先指标（预示未来） |
| 颗粒度 | 粗糙（一个数字掩盖所有问题） | 精细（每一笔都是思维切片） |
| 归因性 | 难以定位（错在哪？为什么错？） | 天然归因（断点、堵点一目了然） |
| 可干预性 | 考完再改，成本极高 | 随时调整，即时纠偏 |
| 真实性 | 可能受运气、押题、状态影响 | 长期积累，无法伪装 |

孩子刚进入高年级，老师、教材、家长三方面如果恰好都开始往“学习方法和思维结构”上走，效果可能比单纯增加学习时间好得多。我觉得我们这个开局很好，起码到现在我感觉我们的教学理念终于开始重合了。再就是去年的时候娃告诉我一个让我感到很意外的事情，就是期末考试的时候，学校竟然是把成绩较为优秀的孩子放在一个考场，成绩落后的孩子集中在一个考场。娃说老师说为了让皮孩子不影响优秀的学生更好的发挥。虽然这样的做法涉嫌成绩歧视，但是不难看出这种老牌学校的传统思维就是想尽一切办法保住高段成绩，甚至在教学上不惜调整使用弃车保帅的做法。我不由得倒吸一口凉气，如果我没有拉住孩子的成绩，她又会在学校面临什么样的待遇和场景。

广告自己分辨，反正这篇不是。

那我们先画两个直角，底在同一个平面上对齐，然后垂直那个线就平行了。那我们知道三角形它的三条边是互相有交点的，也就是说你直角平行是不可能出现三角形的。那么只有这两个角不可以同时是90才行。然后垂直的两条线必然互相往里面形成交叉，这才有可能构成一个三角形。这样就必然导致三个角之和不可能大于180。那为啥等于180呢，因为它肉眼可见等于180，请直接用眼睛看：

再继续拉大这个角他就变成了一个平角了，就不存在什么三角不角的。

四边形也是一样的，更好用折纸法证明，用正方形来向内折四个角就完事了。当然像一些数学大神是不屑于用肉眼观察法的，但是我们是小学生学习，怎么直观怎么来就行了。

当然我们也可以正儿八经的来证明它为什么是等于180

![](https://mmbiz.qpic.cn/mmbiz_png/TZaiaIvaGzrcDHO1nxoicpspQTXqYB70ZJJrSBl6Jjf8S3ca6QU136LkPrrKvSV7esAlx7ywOq1sjRxy2DUK0Iow/640?wx_fmt=png&from=appmsg)

画一条经过顶点A且平行于边BC的直线DE。

由于AB是平行线DE和BC的截线，因此p = b（内错角相等）当然这个地方小学生还没学，我们可以告诉他们这就是相等的啦

同理，q = c。

那还是肉眼可见法：p+a+q=180，又因为上面的p = b  q = c

等量代换得：a + b + c = 180°

那恭喜小学生，证明了人生中第一个几何定理。

那既然都学会内角和定理了，来都来了，外角定理一起学了呗。

外角定理：“三角形的一个外角等于与它不相邻的两个内角之和。”

![](https://mmbiz.qpic.cn/mmbiz_png/TZaiaIvaGzrcDHO1nxoicpspQTXqYB70ZJScO6mAvG96kyW3zhSB3zqnBHkjYibc9FzqJkZFegH8T18Fhf46m0IYw/640?wx_fmt=png&from=appmsg)

这里有一个阿尔法，这个阿尔法等于什么呢？

那我们已经知道了a + b + c = 180°

b + α = 180°  因为肉眼可见法，这俩就是一个平角

我们来等量代换：知道了b=180°-a-c

那么代进去：180°-a-c+α=180°

整理得到：α=a+c

这不就完事了，那反正都学到这里了，干脆全部学完嘛：

三角形所有外角的和等于360°。

因为我们知道一个角等于不相邻的两个内角之和，那么这三个外角加起来就是每个内角加两次呗，那不就是两个180°，所以是360°嘛。

由此我们可以猜多边形外角定理：“凸多边形所有外角的和等于360°”。

![](https://mmbiz.qpic.cn/mmbiz_png/TZaiaIvaGzrcDHO1nxoicpspQTXqYB70ZJAA5Yb3d2k4KwGyELP7FFdJmMF6JWKBlg0j48EZyreFd0cO6cHQjn0Q/640?wx_fmt=png&from=appmsg)

如果是一个凸的任意多边形，甚至不规则形状，你就站起来，绕着这个东西走一圈，无论它多么奇形怪状，你都走一圈，一圈就是一个圆，无论你怎么走。你都最多走一圈就包圆它了，因此任何的凸多边形的外角就是360°。这就是走路大法。虽然这不是一个正经的证明方法，但是他可以帮助小学生快速的理解为什么是这样。

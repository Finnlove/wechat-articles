       这是我让deepseek写的一个挂件，我是故意让他从2月13开始算的，它会自动获取Nasa官网图片换背景。那么同样的，我们可以做一个打卡挂件，然后连通到notion的数据库，再把这个数据库授权给github，新建一个网页用来显示数据统计图，它会直接实时显示。言出法随式的写HTML或者svg，不需要懂一句代码。本人完全不懂任何代码知识，但是我明白大体的流程，我就是和它聊天，它就给我做好了。

      所以我觉得目前单纯的学堆代码意义不大，更重要的是能发挥创意，要能想出来让代码为我们做什么。也就是从单纯的AI到现实世界的应用，成为我们看得见摸得着的东西，这个才是未来的发展方向。

      再就是，我觉得拥有一个教育邮箱和一个github账号很重要，这两个东西对于普通人来说几乎是打开前沿信息的钥匙一样，并且，他们都是完全免费的。我现在有个想法，我想让ai为我讲解微软少儿编程的课程，我觉得这一点也不难做到。加上可以利用字节的编程工具，这几乎就是白嫖的专业级别教练，并且它还不厌其烦的为我把代码全部加上注释，这就很奈斯。

     我之前就很喜欢网页设计，可是我完全不懂，现在好了，只要聊天就能做了😂。前几天我注意到娃喜欢玩推箱子游戏，可以从这个地方入手带她接触控制AI学习逻辑。

     目前我只会静态的一些小玩意，接下来我会试试做动画。我知道的是css Java Python svg等都可以做动画，比较简单的是css动画。

       此外，做美篇的时候也可以直接用代码做那个题图自由布局，因为那个就是一个最基础的HTML，所以从此美篇题图随心所欲，直接用代码控制生成就行了，会员都省了😂😂

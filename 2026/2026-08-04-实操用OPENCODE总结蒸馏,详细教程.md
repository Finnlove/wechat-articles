下面来翻译一下：

简单的说就是他现在有一个东西叫flowus  cli,以前我们用这样的多维表笔记啥的会觉得很难学。但是现在你不用学了，因为有CLI。

CLI怎么用呢，很简单：

```
给我安装flowus cli，并且执行以下命令：npx skills add next-space/flowus-skill --skill flowus-cli
```

打开opencode,复制上面的话丢进去就好了。接下来一切都是自动的，完事他会告诉你我装好了。然后它会告诉你需要机器人bot token,去息流建一个，拿到以后复制黏贴回来。然后让opencode用环境变量配置token，一切准备就绪。

然后你就可以这样用，比如爬博主的公众号：

```
网页端爬取某个博主关于数学学习的全部文章，保存为MD文件，并且提取学习方法论，把方法论文章保存到息流并且调用callout和块颜色等进行美化，搭配适当的emoji点缀。
```

就发这段话给opencode,然后你就等着它来全部执行好。

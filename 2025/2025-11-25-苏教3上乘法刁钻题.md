```
  □ 7 □  ×     7  ————————-——   2 □ 1 8  
```

这个是考察乘法和位值原理的应用，这类题目主要是要靠猜，但是不是说瞎猜，而是借助我们已经知道的数学工具来有的放矢地猜。

那这里其实可以利用的地方就是头和尾，头这里结果固定在2，那很显然这个百位乘以7必须小于或者等于2000左右，那我们就要从乘法口诀的7字入手，很快想到3×7=21，或者4×7=28，再大就不合适了。

再来看尾数是8，那它也要经过和7相乘才能得到，想到4×7=28  那这个8一定是这样来的，所以有

```
  □ 7 4  ×     7  ————————-——   2 □ 1 8  
```

那就剩下前面这个百位了，我们上一步知道了4×7=28，又十位告诉我们是7，那么十位算出来是490，那也就是说，这里有490+28=518了，如果我们前面选择百位是4，那就是2800+518，很显然这个会导致千位要变成3，不对，所以选3×7=21试试：

根据位值原理：2100+490+28=2618，正好三个数字符合我们的题目要求，剩余的空格填6即可。

利用位值原理和乘法口诀表，这类题目全部都可以用奥数题变成送分题

```
  □ 5 □×     6-------3 □ 2 4
```

这个也是一样的，还是位值原理已知有十位是5×6，所以十位结果为300

又尾数是4，根据乘法口诀表有：4×6=24   9×6=54

我们来猜，因为题目告知最后两位是24，代入前面的两个备选项有300+24=324 和300+54=354，可以排除54，得个位是4

前面这个就更简单啦，因为后面是324，所以千位是6×5=30，千位结果就是3000

```
    5 5 4×       6----------  3 3 2 4
```

算出来就可以了，小时候不会的现在觉得超级简单。

那么我们进阶一下：

```
  A B C D×       9--------------  D C B A
```

这个差不多是四五年级的难度，所有数字都可以用上，但互相不能重复

这类题就差把位值原理四个字写在脸上了，明摆着啊。

那先考虑9的乘法口诀嘛，全部写出来1 →9=9  2→9=18  3→9=27   4→9=36   5→9=45   6→9=54  7→9=63  8→9=27  9→9=81

那么D×9=BA     A×9=DC（大致）我们来猜：

注意到这个数的结果是四位数，所以这个A乘以9不能搞得太大，因为再大一点点它就变万位了，A要么就干脆是1，这样1000乘以9等于9000

那D就是9了，因为9×9=81，这里很容易理解吧。

那么我们知道前面有9000了，所以百位不能进位，同时B也不能是1，那就只能是0啦

```
  1 0 C 9×       9-------------  9 C 0 1
```

那这个式子就变成了这个样子，所以这里实际就是要算：

```
    C 9×     9-------  C 0 1
```

还是位值原理：（C×10+9）9=C×100+1

展开有90C+81=100C+1

简化得：80=10C 故C=8

原式为：

```
  1 0 8 9  ×     9-------------  9 8 0 1
```

很简单吧

**先说背景**：harness 官方仓库才建 2 天，rc.6 版本，官方 README 自己声明"会有破坏性变更"——整个生态都是 beta，别一次装太多。

**值得装的**：

| 插件 | 是什么 | 值不值 |
| --- | --- | --- |
| `@linxin666/dsh-web-ui-all@0.1.12` | web UI 全家桶：任务看板、git 图、文件/预览/SCM 侧栏、token 实时统计、9 套皮肤 | ⭐ 最值得，1.5k star，维护最活跃，唯一推荐必装 |
| `@liustack/modlens` | 给纯文本模型加"看图"能力（粘贴图片它帮你读） | 👍 想要 vision 时再装，需要另配一个 Gemini key |
| `awesome-dsh-plugins` | 社区插件雷达索引（288 个，8 小时自动扫描） | 📌 加书签，自己淘 |
| `deepseek-harness-desktop` | Electron 桌面壳（免 Node、托盘） | 👌 想摆脱浏览器时用 |

所以我个人觉得opencode继续用，因为免费额度多，继续蹬也不心疼，鲸娘这边挂一个agnes蹬轻度任务。重度任务上deepseek api就好了。

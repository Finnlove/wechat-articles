这样我们就可以把思维过程分离出来，形成模型经验积累

```
# 代入变量pear_tree + (2 * pear_tree) + (pear_tree + 12) = 212
```

![](https://mmbiz.qpic.cn/mmbiz_png/TZaiaIvaGzreRWHicQdqUmwOgSAWz1frFWK24Ga8Jiaf7dxvQ0RxAJrqEUn4rjiaKc5qYTHzibibH5kMdOGtrkFPxIyA/640?wx_fmt=png&from=appmsg)

所谓合并同类项就是把你能算的部分先算出来，其他不能算的部分你就抄，抄完整

```
# 合并同类项(1 + 2 + 1) * pear_tree + 12 = 212# 计算后得到：4 * pear_tree + 12 = 212
```

![](https://mmbiz.qpic.cn/mmbiz_png/TZaiaIvaGzreRWHicQdqUmwOgSAWz1frFW4p5XKNxCCPJFpjvic0NE19dXbu9Txq4ic2BmEgEyd0UMkyKxasNa7SYQ/640?wx_fmt=png&from=appmsg)

最后利用逆运算就可以了

```
# 第一步：处理加法逆运算4 * pear_tree = 212 - 124 * pear_tree = 200  
# 第二步：处理乘法逆运算pear_tree = 200 / 4pear_tree = 50
```

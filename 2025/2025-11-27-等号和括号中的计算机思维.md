在苏教三年级的时候我们会遇到小括号这个数学符号，还有我们的老朋友等号。很多的小朋友对这两个符号的运算作用理解的不是很透彻，特别是很多老师也会忽略这两个符号强大的逻辑运算作用。

在一年级，我们知道等号的作用就是告诉我们它相当于一个天平，等号左边全部的东西等于等号右边全部的东西。很多有阅读障碍的孩子理解不了等号的左边等于等号的右边这句话，因为这句话有歧义：

```
A+B=C+D
```

这个式子在高精度语言障碍类型的孩子看来是这样的：

A+B=C+D → B=C  因为他们理解的左边和右边就是贴紧等号的左边和贴紧等号的右边，为什么我知道呢？因为我娃就是这个类型的。所以我们讲解的时候一定要说：等号左边全部的东西等于等号右边全部的东西。这样娃才不会混淆。

所以我们借助括号来说明这个问题：等号的两边就是像是有两个括号包住的房间：

```
（A+B)=(C+D)
```

所以我们说的等号两边相等实际是这样的。这看起来很废话，但是对于一些孩子的理解来说至关重要。为了让孩子明白这种相等是如何发生的，我们用具体的例子来说明：

```
5+4=3+6
```

这里每个数字都不相等，写出来长的也不一样，那么他们为什么可以相等呢？因为他们的运算结果相同！因此他们的中间实际存在着一个共性的桥梁：

```
5+4=9  3+6=9  所以有  5+4=9=3+6 
```

因此这个中间的桥梁就是等量关系产生的依据所在，这正是我们进一步理解等量代换的关键步骤。

我们再来看括号的作用：我们都知道在四则运算中，有括号先括号，先乘除后加减的口诀。

括号的第一个作用就是改变运算顺序，起到优先级的提示作用

实际上在我们上述等式中，括号也是在发生作用的：

```
5+4=9  3+6=9  所以有  （5+4）=（3+6）
```

我们可以看到，要证明两边相等，我们必须先计算括号的部分，只不过在等式中，这个两边包住的括号被隐藏了而已。如果我们不先运算括号里的结果，就无法直接比较两者是否相等。

下面我们来理解等号的赋值作用，这也是三年级孩子在做等量代换时最难理解的部分。在计算机语言中，等号起到赋值的作用，例如：

```
A=9  
```

这句话的意思是，让A等于9，此后的程序中，A会全部默认为等于9。接下来我会让你一秒钟学会PYTHON中的赋值：

```
# 第一部分：简单的赋值 - “起名字”# 我们给数字5起了一个名字，叫 AA = 5print("A 的值是:", A)  # 这会输出：A 的值是: 5# 我们给数字3起了一个名字，叫 B  B = 3print("B 的值是:", B)  # 这会输出：B 的值是: 3# 第二部分：使用“名字”进行计算 - “呼叫代号”# 现在我们可以用 A 和 B 来代替数字进行计算C = A + B  # 这行的意思是：计算 A+B 的结果，然后给这个结果起个新名字叫 Cprint("A + B 等于:", C)  # 这会输出：A + B 等于: 8
```

是不是超级简单，理解等号有赋值的作用意义重大，因为它就相当于数学中的换元法。很多小朋友不会等量代换就是因为没有理解这个赋值的等量作用。

那么这个理解过程是循序渐进的：

**第一阶段：实物赋值**  
请从一大盒子字母积木中找到所有的A型字母给我。然后数一数，这里有几个A？这个游戏在幼儿园就可以玩了。

**第二阶段：数字赋值**

```
A = 5# 请计算：A + A = ?# 请计算：A + 3 = ?
```

一年级上的所谓的奥数题，眼熟不

**第三阶段：关系赋值**

```
苹果 = 2 × 橘子    # 理解倍数关系橘子 = 3 × 草莓    # 理解倍数关系  # 请问：苹果 = ? × 草莓
```

**这里就是我们说的需要等量的桥梁关系了，从这里就有小朋友开始不会了。为了学会这种题目，我们需要括号来帮忙：**

```
苹果 = 2 × 橘子    橘子 = 3 × 草莓  我们把橘子和草莓这里用括号打个包： （橘子） = （3 × 草莓）这边的式子也包起来：(苹果 )= (2 × 橘子)然后我们去找相同，发现这两个式子都有橘子：我们用（3 × 草莓）去代替橘子
```

在这里发生了非常重要的一步：等量代换，也就是赋值作用，实际上这里的意思是让橘子等于3个草莓

大部分小朋友不会等量代换的原因就是：搞不清楚哪两个“包”相等，会漏掉前面的倍数或者系数。

**因此我们的式子继续：**

```
(苹果 )= (2 × 橘子)变成：（苹果）=（2×（3 × 草莓））（苹果）=（6×草莓）
```

**也就是说原来一个苹果等于两个橘子，而一个橘子就等于三个草莓，那么两个橘子自然就需要六个草莓。有相当的一部分的孩子能说清楚这个代换过程，也明白原理，但是无法准确的用数学式子去表达这个过程。也就是说孩子的抽象数学表达能力和具体的观察描述存在脱节现象，这种现象的背后就是缺失这种把具体问题用计算机逻辑来理解和表达的能力。**

**我们的数学学习其实就是一种计算机语言的学习，因为我们要把具体的事物变化从文字表述翻译为数学符号表达的语言，因此我们需要计算机逻辑的帮助。**

### **数学：人类最古老的“编程语言”**

| 计算机编程 | 数学学习 | 核心能力 |
| --- | --- | --- |
| `变量 = 值` | `设苹果 = x` | 代数化：给事物起符号名或者赋值 |
| `函数(参数)` | `f(x) = 2x + 1` | **模式化** ：建立输入输出的数量关系 |
| `if-else条件` | `如果 x > 0，那么...` | **逻辑判断** ：条件推理 |
| `循环` | `求和 ∑` 、`连乘 ∏` | **重复模式** 简洁表达，例如乘法是连续相加 |
| `调试` | `验算` 、`反证` | 验算和逆运算 |

**其实这俩压根就是一回事嘛**

**那上面的题目我们只要理解了**

```
（橘子） = （3 × 草莓）
```

**这个就是赋值，此后所有的橘子都用三个草莓代替，不就学会了，还等来等去想不明白做啥？这就是一个死的计算机命令，执行就完事了。这其实就是数学教育的目标：**把需要想来想去的问题，变成有明确指令和有路径的操作**。**

**所以搞懂这些我们来看终极苏教三上奥赛题：**

王师傅要加工一批零件，第一周加工了总数的一半还多20个，第二周加工了剩下部分的一半又少10个，还剩下160个，第三周全部加工完了，问：王师傅一共加工了多少个。

这个题目画图当然没问题，但是我们说代数法也要学会，因为代数法能打通方程思维。特别是很多小朋友，他能看懂画图解题的过程，但是他自己是没有这个能力去画图做题的，这是最大的问题所在。我家娃就是那种能看懂我画的图，但是自己画就不会了，只能用说话的方法来解题。

那我们就用说话方程来解决这个问题：

```
第一周：（一半+20个 ）＋（一半-20个）=总数
```

很多孩子第一步就会错，因为它不知道这两个括号为什么一个是减去20一个是加上20，因为第一步的等量关系是这样来的：

```
总数=一半+一半      这一步绝大多数孩子都很快的能发现一半+20又该如何变会总数呢？一半+20+一半多了20啊，那么再减去20不就可以了所以是（一半+20）+（一半-20）=总数
```

来看第二周，由于第一周的一半+20做完了，剩下的部分就是

```
一半-20个
```

**一定要理解这里还有一个-20 的存在，这是关键。这就是第二周的新总量**

**（一半-20），那么第二周要把这个新的包再对半分并减去10：**

```
（总数的一半-20)的一半-10
```

**我们发现，做完上面的部分，还剩下160个，这是一个确切的数字，因此我们可以利用这个确定的数字来还原第二周的新总量。**

**第二周的新总量=（一半-20）=（总数的一半-20）的一半-10+160**

我们把确切的数字部分算出来：

**第二周的新总量=（一半-20）=（总数的一半-20）的一半+150**

****第二周的新总量=**（总数的一半-20）的一半+150**

**因此**（总数的一半-20）的一半=150****

****这里是第二个学渣无力关键点，因为他们不理解一半+150=新总量中存在的等量代换关系，既然一半＋一半等于总数，那么其中的一半换成150的情况也能还原成为总数，也就意味着这个一半就是等于150的。****

**我不知道别人的学习情况如何，反正我家娃必须这样说才能学明白，这也是反复实践观察出来的一个点：**

由****（总数的一半-20）的一半=150****

**我们可以知道****（总数的一半-20）=300，因为一半加一半可以还原原来的总数。******

******所以我们打开这个括号包裹：******总数的一半-20=300************

************那么我们可以对确切的数字部分进行计算：************总数的一半=320************************

************************我们再次把两个一半还原总数，有：************************总数的一半+************************总数的一半=总数************************************************************************

************************************************************************因此总数=320+320=640************************************************************************
